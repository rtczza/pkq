## 1. RPM 系统

### 1.1 rpm

**语法：** `rpm [选项] <操作>`

#### 查询操作 (`-q` / `--query`)

**包选择选项（筛选查询范围）：**

| 选项 | 说明 | 示例 |
|------|------|------|
| `-a, --all` | 查询所有已安装包 | `rpm -qa` |
| `-f, --file FILE` | 查询拥有已安装文件 FILE 的包 | `rpm -qf /usr/bin/bash` |
| `--path PATH` | 查询拥有路径的包（含未安装文件） | `rpm -q --path /usr/bin/bash` |
| `-g, --group GROUP` | 查询指定组中的包 | `rpm -qg System/Environment` |
| `-p, --package FILE` | 查询未安装的 .rpm 文件 | `rpm -qp package.rpm` |
| `--pkgid` | 按包 ID 查询 | `rpm -q --pkgid 0x1234` |
| `--hdrid` | 按头 ID 查询 | `rpm -q --hdrid 0x5678` |
| `--triggeredby PKG` | 查询被 PKG 触发的包 | `rpm -q --triggeredby bash` |
| `--whatprovides CAP` | 查询提供指定能力的包 | `rpm -q --whatprovides "libssl.so.3"` |
| `--whatrequires CAP` | 查询需要指定能力的包 | `rpm -q --whatrequires bash` |
| `--whatconflicts CAP` | 查询与指定能力冲突的包 | `rpm -q --whatconflicts bash` |
| `--whatobsoletes CAP` | 查询废弃指定能力的包 | `rpm -q --whatobsoletes bash` |
| `--whatrecommends CAP` | 查询推荐指定能力的包 | `rpm -q --whatrecommends bash` |
| `--whatsuggests CAP` | 查询建议指定能力的包 | `rpm -q --whatsuggests bash` |
| `--whatsupplements CAP` | 查询补充指定能力的包 | `rpm -q --whatsupplements bash` |
| `--whatenhances CAP` | 查询增强指定能力的包 | `rpm -q --whatenhances bash` |
| `--tid TID` | 按事务 ID 查询 | `rpm -q --tid 1234567890` |
| `--dupes` | 列出重复安装的包 | `rpm -qa --dupes` |
| `--nomanifest` | 不将非包文件作为清单处理 | |

**包信息选项（输出什么信息）：**

| 选项 | 说明 | 示例 |
|------|------|------|
| `-i, --info` | 显示包详细信息 | `rpm -qi bash` |
| `-l, --list` | 列出包内文件 | `rpm -ql bash` |
| `-R, --requires` | 列出包的依赖 | `rpm -qR bash` |
| `--provides` | 列出包提供的能力 | `rpm -q --provides bash` |
| `--conflicts` | 列出包冲突 | `rpm -q --conflicts bash` |
| `--obsoletes` | 列出包废弃 | `rpm -q --obsoletes bash` |
| `--recommends` | 列出推荐依赖 | `rpm -q --recommends bash` |
| `--suggests` | 列出建议依赖 | `rpm -q --suggests bash` |
| `--supplements` | 列出补充依赖 | `rpm -q --supplements bash` |
| `--enhances` | 列出增强依赖 | `rpm -q --enhances bash` |
| `--changelog` | 显示变更日志 | `rpm -q --changelog bash` |
| `--changes` | 显示带完整时间戳的变更 | `rpm -q --changes bash` |
| `--scripts` | 显示安装/卸载脚本 | `rpm -q --scripts bash` |
| `--triggers` | 显示触发器脚本 | `rpm -q --triggers bash` |
| `--filetriggers` | 显示文件触发器 | `rpm -q --filetriggers bash` |
| `--xml` | 以 XML 格式输出元数据 | `rpm -q --xml bash` |
| `--last` | 按安装时间排序 | `rpm -qa --last` |
| `--filesbypkg` | 按包列出所有文件 | `rpm -qa --filesbypkg` |
| `--filecolor` | 列出文件颜色（0=noarch, 1=32bit, 2=64bit） | `rpm -q --filecolor bash` |
| `--fileclass` | 列出文件类（libmagic 分类） | `rpm -q --fileclass bash` |
| `--filecaps` | 列出文件 POSIX1.e capabilities | `rpm -q --filecaps bash` |

| `--dump` | 转储文件基本信息（含 -l） | `rpm -ql --dump bash` |
| `-s, --state` | 显示文件状态（含 -l） | `rpm -qs bash` |
| `--qf, --queryformat FMT` | 自定义输出格式 | `rpm -q --qf '%{NAME}-%{VERSION}\n' bash` |

完整标签列表：`rpm --querytags`


| `--noscripts` | 不执行验证脚本 |
| `--nosignature` | 不验证签名 |

| `--nomtime` | 不验证修改时间 |
| `--nomode` | 不验证文件模式 |

#### info 子命令

```
dnf [options] info [<package-file-spec>...]
```
显示已安装和可用包的描述和摘要信息。

#### list 子命令

```
dnf [options] list {--all|--installed|--available|--extras|--obsoletes|--recent|--upgrades|--autoremove} [<package-file-spec>...]
```

#### provides 子命令

```
dnf [options] provides <provide-spec>
```
查找提供指定能力的包。查找顺序：
1. 匹配所有包的文件 provides
2. 匹配所有包的 provides
3. 假设是命令，尝试 `/usr/bin/`、`/usr/sbin/`、`/bin/`、`/sbin/` 前缀
4. 返回 "No Matches found"

#### search 子命令

```
dnf [options] search <package-file-spec>...
```
在包名和描述中搜索，分名称精确匹配、名称和摘要匹配、摘要匹配三个层次。

## 3. 跨系统命令对照表

### 3.1 包详情查询

| 场景 | RPM | DEB | 输出差异 |
|------|-----|-----|---------|
| 已安装包详情 | `rpm -qi PKG` | `dpkg -s PKG` / `apt show PKG` | RPM 含 Install Date/Signature; DEB 含 Installed-Size/Download-Size |
| 仓库包详情 | `dnf info PKG` / `dnf repoquery -i PKG` | `apt show PKG` / `apt-cache show PKG` | RPM 含仓库来源/大小; DEB 含 APT-Sources/Download-Size |
| 所有版本 | `dnf repoquery --show-duplicates PKG` | `apt-cache show PKG` (默认显示所有版本) | |

### 3.2 文件列表

| 场景 | RPM | DEB |
|------|-----|-----|
| 已安装包文件 | `rpm -ql PKG` | `dpkg -L PKG` / `dpkg-query -L PKG` |
| 仓库包文件 | `dnf repoquery -l PKG` | `apt-file list PKG` |
| 仅配置文件 | `rpm -qc PKG` | `dpkg -L PKG \| grep /etc` (无直接选项) |
| 仅文档文件 | `rpm -qd PKG` | `dpkg -L PKG \| grep /usr/share/doc` (无直接选项) |
| 文件+大小+时间 | `rpm -ql --dump PKG` | 无直接等价 |

### 3.3 文件归属

| 场景 | RPM | DEB |
|------|-----|-----|
| 已安装文件归属 | `rpm -qf /path` | `dpkg -S /path` / `dpkg-query -S /path` |
| 未安装文件归属 | `dnf provides /path` | `apt-file search /path` |
| 命令归属 | `dnf provides CMD` (自动加前缀) | `apt-file search CMD` |
| 能力归属 | `dnf provides "libssl.so.3"` | `apt-file search libssl.so.3` |

### 3.4 依赖关系

| 场景 | RPM | DEB |
|------|-----|-----|
| 正向依赖（本地） | `rpm -qR PKG` | `apt-cache depends PKG` |
| 正向依赖（仓库） | `dnf repoquery --requires PKG` | `apt-cache depends PKG` (使用缓存) |
| 依赖+提供者 | `dnf repoquery --deplist PKG` / `yum deplist PKG` | 无直接等价 |
| 递归依赖 | `dnf repoquery --requires --recursive --resolve PKG` | `apt-cache depends --recurse PKG` |
| 反向依赖（本地） | `rpm -q --whatrequires PKG` | `apt-cache rdepends PKG` |
| 反向依赖（仓库） | `dnf repoquery --whatrequires PKG` | `apt-cache rdepends PKG` (使用缓存) |
| 递归反向依赖 | `dnf repoquery --whatrequires --recursive PKG` | `apt-cache rdepends --recurse PKG` / `apt-rdepends -r PKG` |
| 仅重要依赖 | 无 | `apt-cache depends -i PKG` (仅 Depends/Pre-Depends) |
| 按类型筛选 | 无 | `--no-recommends` `--no-suggests` 等 |

### 3.5 搜索

| 场景 | RPM | DEB |
|------|-----|-----|
| 按关键词搜索 | `dnf search KW` | `apt-cache search KW` / `apt search KW` |
| 按名称搜索 | `dnf search --name KW` | `apt-cache search --names-only KW` |
| 正则搜索 | 无直接等价 | `apt-cache search 'regex'` |
| 按文件搜索 | `dnf provides /path` | `apt-file search /path` |

### 3.6 能力 (provides)

| 场景 | RPM | DEB |
|------|-----|-----|
| 包提供什么 | `rpm -q --provides PKG` | `apt-cache show PKG` 看 Provides 字段 |
| 谁提供某能力 | `rpm -q --whatprovides CAP` / `dnf provides CAP` | `apt-cache search CAP` (间接) |

### 3.7 源码包

| 场景 | RPM | DEB |
|------|-----|-----|
| 包的源码包名 | `rpm -qi PKG` 看 Source RPM 字段 | `dpkg -s PKG` 看 Source 字段 |

| 源码包→二进制 | 从 repo metadata 反查 sourcerpm 字段 | 从 Packages 反查 Source 字段 |

### 3.8 变更日志

| 完整时间戳 | `rpm -q --changes PKG` | |

|------|-----|-----|

## 4. pkq 命令参考

pkq（Package Query）在 rpm/dnf 与 dpkg/apt 之上提供统一查询语法。
以下为 **v0.2.0 实际实现的全部命令与参数**。

### 全局选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `-o, --output FORMAT` | 输出格式（human / json） | human |
| `--refresh` | 强制刷新仓库元数据缓存 | false |
| `--offline` | 离线模式，仅使用本地缓存 | false |
| `--cache-ttl SECONDS` | 缓存 TTL | 86400（24h） |
| `--legacy-exit-code` | 兼容模式：无论结果如何均以 0 退出 | false |

退出码语义：`0` 查询命中 / `1` 未找到或部分未达成 / `2` 错误。

### 4.1 info — 软件包详情

```bash
pkq info <pkg> [--repo]
```

本地优先查询；未安装时自动回退仓库并输出安装命令（`apt-get install` / `dnf install`）。

### 4.2 list — 包内文件列表

```bash
pkq list <pkg> [--all] [--repo]
```

输出按路径字典序排序（同目录文件聚合）。默认过滤 `.`、`/usr`、`/etc` 等
公共目录，`--all` 显示完整列表。本地未安装时自动检索仓库并给出安装引导。

### 4.3 owns — 文件归属

```bash
pkq owns <path> [--all] [--repo]
```

支持绝对路径与通配符（`*/bin/unzip`）。查询公共目录（如 `/etc`）时，
归属包超过 50 个默认限流展示，`--all` 查看全部。

### 4.4 deps — 正向依赖

```bash
pkq deps <pkg> [--repo]
```

按 `依赖 / 推荐 / 建议 / 冲突 / 替换` 分段输出。RPM 端自动将 soname、
`config(...)` 等能力反查为真实包名，并保留版本约束（如 `glibc (>= 2.17)`）。

### 4.5 rdeps — 反向依赖

```bash
pkq rdeps <pkg> [--all] [--installed-only] [--repo]
```

语义对齐 `dnf repoquery --whatrequires`：匹配目标包的名称、显式
provides 与主执行文件路径，且仅匹配强依赖（Requires）。默认限流 50 条，
`--all` 查看全部。底部汇总与列表严格一致。

### 4.6 search — 搜索

```bash
pkq search <keyword> [--regex] [--names-only] [--files-only]
           [--all] [-i, --installed] [--repo] [--max-files N]
```

- 关键词匹配包名与摘要（不对描述正文做子串匹配，避免噪音）
- 词边界分层排序：精确/前缀/包含 > 摘要词边界 > 模糊命中
- 以 `/` 开头或含通配符时等价于 `owns`（本地无结果自动回退仓库）
- 摘要模糊命中（如 sudo→sudoku）折叠为单行「可能相关」段，`--all` 展开
- `--installed-only`（别名 `-i`）仅搜本地已安装

### 4.7 source — 源码包与二进制包互查

```bash
pkq source <pkg>
```

自动识别输入是二进制包名还是源码包名：列出该源码包生成的全部二进制包，
并标注 `[已安装]` / `[未安装]`（安装状态按 name+version+release+arch
精确匹配）。排序：主同名包置顶 > 已安装优先 > 主架构 > 字母序。

### 4.8 changelog — 变更日志

```bash
pkq changelog <pkg> [--repo]
```

本地无变更日志时自动检索仓库（RPM 端拉取 repodata other.xml）。

### 4.9 cache — 缓存管理

```bash
pkq cache status                    # 各缓存目录占用
pkq cache update                    # 强制刷新仓库元数据
pkq cache clean [target] [--yes]    # 清理：all | index | repos | contents
```

- `cache update` 逐源输出刷新进度：`✓` 在线成功、`△` 在线失败已回退
  本地缓存（附原因，如 `HTTP 401（认证失败）`/`响应超时`）、`✗` 彻底失败
- **有源未刷新成功即视为失败**：输出 ⚠ 提示并返回退出码 `1`（脚本可检测）
- `cache clean` 默认需追加 `--yes` 确认

### 4.10 退出码与 JSON

| 退出码 | 含义 |
|--------|------|
| `0` | 查询命中 / 更新全部成功 |
| `1` | 未找到 / 部分未达成（如部分源刷新失败） |
| `2` | 错误（无效参数、网络与缓存皆不可用等） |

`--output json` 对 info/deps/rdeps/search/owns 提供 JSON 输出；
`--legacy-exit-code` 可回退 v0.1 的恒 0 退出行为。
